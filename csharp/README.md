Diagram Refactoring Kata - C# (with checklists)
================================================


In the class 'DiagramPrinter' there are several methods with awkward arguments for testing. Use the checklists to get them ready for testing.

Instructions 
-------------

Use the following steps, starting with the 'PrintSummary' method.

1. Use the checklist 'Adapt Parameter' to adapt the FlowchartDiagram.
2. Use the checklist 'Discover Adapter Interface' to add methods to the new Adapter class.
3. User the checklist 'Extract Interface' to create a testable interface.
4. Write a unit test for this method that checks a scenario where the diagram is not null.

When you have completed these steps, use these same steps and the same checklists to write tests for the PrintDiagram method.

The remaining methods will need additional checklists to get them under test.
